## ✨ About

**Bookmark Vault** is a lightweight REST API for saving and managing bookmarks.

Built with **Bun, TypeScript, SQLite, GitHub Spec Kit, and AI-assisted development**.

---

## 🚀 Run

```bash
git clone https://github.com/alishojaeix/bookmark-vault.git
cd bookmark-vault
bun install
bun run src/db/init.ts
bun run dev
```

Then open:

```text
http://localhost:3000
```

Health check:

```text
http://localhost:3000/health
```
